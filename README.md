# AI Atlas / 2026

Интерактивный атлас развития AI: история, события 2026 года и российские экосистемы. Срез — **21 октября 2026 года**.

[Открыть сайт](https://p1um.github.io/ai-digest/) · [Начать презентацию](https://p1um.github.io/ai-digest/#present/intro)

## Открыть и провести презентацию

- [Начать показ](ai-atlas-2026/dist/index.html#present/intro): 25 экранов: история, ключевые повороты, достижения и направления развития. На главной странице — кнопка **«Начать показ · 27 минут»**.
- **← / →** — предыдущий / следующий экран; **Home / End** — начало / выводы; **Esc** — закрыть подробности или вернуться в атлас. Кнопка **«На весь экран»** включает полноэкранный показ. Внизу можно выбрать любой экран, вверху — раздел.
- [Открыть каталог](ai-atlas-2026/dist/index.html#events): все события, фильтры и первоисточники для самостоятельного чтения и вопросов.
- [Сценарий презентации](ai-atlas-2026/research/PRESENTATION.md): маршрут на 27 минут и до 10 минут вопросов.

Для показа с Mac достаточно открыть `index.html` в браузере. Файл работает самостоятельно; сеть нужна для перехода к внешним источникам. Для переноса достаточно одного `index.html`.

Маршрут: **истоки → ключевые повороты → достижения и сбои → направления развития → вопросы**.

## Содержание атласа

- 41 выбранное событие, 14 организаций и экосистем и 6 направлений.
- Историческая глава: шесть ранних этапов и годы 2017–2026; выбор года, последовательный просмотр и показ всех лет.
- Пояснения механизмов и ограничений по кнопке «Как это работает».
- Режим показа: Тьюринг и правила, обучение, Transformer, предобучение, ChatGPT, MoE / DeepSeek / Kimi, reasoning, RAG и агентный поиск, инструменты, skills, идеи Карпати, SDD, Kimi Agent Swarm, компилятор, Hugging Face, AlphaEvolve, autoresearch, мультимодальность, роботы, Project Vend, российские продукты и направления развития. Факты, ограничения и заметки для выступления открываются поверх экрана.
- Блок «Алиса и ГигаЧат», поиск, фильтры и подробные карточки с условиями доступа.
- Первоисточники, экспорт JSON и печать. Количество карточек описывает редакционную подборку.

История встроена в `index.html`; для переноса всей инфографики достаточно этого файла. [Отдельная версия истории](ai-atlas-2026/dist/history.html) также доступна. После обновления файлов открытую страницу нужно перезагрузить.

## Обновление

После правок истории, событий или сценария выполнить:

```sh
python3 ai-atlas-2026/research/build_history.py
```

Сборка обновляет `history.html`, встроенную историческую главу и режим показа в `index.html`. Исходники режима показа находятся в `ai-atlas-2026/src/presentation.*`; стили настольной истории — в `src/history-desktop.css`. Для изменения только режима показа можно запустить `python3 ai-atlas-2026/research/build_presentation.py`.

Сборка автоматически синхронизирует `events.json` с блоком `script#event-data` основной страницы. Показ имеет собственный связный сценарий в `presentation.json`, реестр источников и заметки выступающего. Каталог сохраняет модельные релизы и другие типы событий; историческая глава — полную хронологию. Старые ссылки на экраны показа перенаправляются к соответствующим новым темам.

Для локального превью при необходимости:

```sh
python3 -m http.server 4176 --bind 127.0.0.1 --directory ai-atlas-2026/dist
```

## Публикация на GitHub Pages

Push в `main` запускает `.github/workflows/pages.yml`: сборку и публикацию только папки `ai-atlas-2026/dist`. Доступен также ручной запуск из Actions. Локальные скриншоты, браузерные журналы и исследовательские черновики не включаются в репозиторий.
